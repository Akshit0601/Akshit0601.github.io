Cosmo Logistics

Warehouse automation using a UR5 arm and an ebot UGV, built for the E-Yantra Robotics Competition — finished 6th out of 200+ teams in India.

ROS2 MoveIt2 Nav2 SLAM
Repository ↗

Introduction

Cosmo Logistics was built as part of the E-Yantra Robotics Competition, whose theme centered on warehouse automation using a UGV and a UR5 robotic arm. The challenge required the system to autonomously navigate the warehouse floor, dock at shelves, and perform pick-and-place operations to move packages between locations, entirely on its own. We developed and validated these algorithms in both simulation and on a physical hardware setup, and the team finished 6th out of 200+ teams across India.

Workflow

Manipulation was handled through the MoveIt2 Motion Planning Python API, using TF2 to manage the coordinate transforms needed for the UR5's forward and inverse kinematics during pick-and-place operations. On the mobility side, the ebot UGV fused wheel and sensor data using an Extended Kalman Filter (EKF) for robust state estimation, built a map of the warehouse using SLAM, and localized itself within that map using AMCL. Path and motion planning for the UGV ran on the Nav2 stack, integrated into the overall system through ROS2's Commander API to coordinate navigation, docking, and manipulation as a single pipeline.
